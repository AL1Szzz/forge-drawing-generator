# 单位配置（profile）

换一家单位**不用改代码**：复制 `default.json` 改名为 `<单位名>.json`，改完放到批次目录里
命名为 **`unit_profile.json`**，跑批时自动生效（也可设环境变量 `FORGE_PROFILE` 指向它）。
不放任何 profile 就用 `default.json`（XX单位口径，老批次行为不变）。

## 字段含义

| 字段 | 用途 | 换单位时怎么改 |
|---|---|---|
| `name` | 仅显示用 | 写单位名 |
| `re_draw` | 标题栏 OCR 图号正则（`build_manifest`） | 按新单位图号编号规则写，如 `G\d{2}\d{5}` |
| `re_draw_ocr` | OCR 图号候选筛选（`ocr2`） | 同上，可放宽松些 |
| `re_draw_anchor` | 料单里抓质保号的锚点（`read_liaodan`） | 必须带一个捕获组，抓到完整图号 |
| `re_draw_qty` | 数量表里抓图号（`read_qty`） | 同上 |
| `re_range` | 图纸文件名"起~止"范围，如 `F24B0001~0099.pdf`（`build_manifest`） | 组1=前缀，组2/组3=起止流水号 |
| `re_pdf_name` | 判断哪些 PDF 是产品图纸、哪些是料单（`build_manifest`） | 写能匹配产品图纸文件名的正则 |
| `re_lu` | **炉号**（6 位）正则，全局通用 | 换单位炉号位数/前缀就改这里 |
| `re_lu_qty` | 数量表里的炉号（`read_qty`） | 与 `re_lu` 一致即可 |
| `re_lu7` | 图纸上另写的长炉号 | 没有就保留默认或设成永不匹配 |
| `materials` | 材质字典，纠正 OCR 错字 | 换成新单位常用钢号，正则里用 `\|` 分隔 |
| `cn_font` / `en_font` | 中英文字体文件 | Windows 一般不用改；Linux/Mac 要换成实际路径 |

## 换单位还需要人工适配的部分（不在 profile 里）

这些跟"图纸版式/卡片格式"绑定，**不是改正则能解决的**，接入新单位前先确认：

1. **标题栏/信息行版式**：`forge_gen.py` 的白盒遮挡区、栏位坐标、标题栏 6 列是按现有图纸图框校准的，新单位图框不同要重新量坐标。
2. **热处理卡片格式**：`read_ht2.py` 的 `%%C`/MTEXT 转义、`read_exb.py` 的 EXB 二进制记录结构，都是针对 **CAXA 电子图板**逆向的；若新单位用别的 CAD，需重新逆向或让对方导出 DXF。
3. **制造大纲/料单表头**：`read_qty.py`、`read_liaodan.py` 的表头列名与列序是按现有大纲写的。
4. **业务规则**：余量档、判型、合锻/取样口径、方块件 +10 都在 `make_batch.py` / `SKILL.md`，属于工艺约定，换单位前必须和客户确认，不要照搬。

**建议流程**：先用 1~2 张图纸手工走一遍（照 `docs/新批次使用说明.md`），确认版式和口径，再批量跑。
